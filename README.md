# Quentin — Create Your Own Universe

Portfolio immersif (React · TypeScript · Vite · Tailwind · Three.js · GSAP · Framer Motion).

## Démarrage

```bash
npm install
npm run dev
```

Build production :

```bash
npm run build
npm run preview
```

## Contenu modifiable

Toutes les données personnelles, projets, matériel et timeline sont centralisées dans :

- `src/data/site.ts`
- Photo : `public/images/quentin.jpg`

Les fiches marquées « à compléter » / « Emplacement » sont volontairement vides pour éviter d’inventer des réalisations.
